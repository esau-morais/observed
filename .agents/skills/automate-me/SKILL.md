# Capture working preferences

1. Read project instructions and the current request. Reuse explicit preferences already supplied.
2. Use only history and files made available for this task. Do not search unrelated transcripts or infer personal traits.
3. Separate explicit instructions, recurring patterns, and one-time choices. Do not turn inference into a mandatory rule.
4. Ask only when an unresolved preference materially changes the result. A specific request needs no interview.
5. Put shared rules in AGENTS.md or an existing relevant skill. Create another skill only for a distinct recurring workflow.
6. Use .agents/skills/<name>/SKILL.md. Preserve the .claude/skills link. Apply unslop.
7. Present changed rules and their basis. A preference for autonomy does not authorize schedules, access grants, publication, or broader permissions.

This records conventions. It does not schedule jobs or replace verification.
