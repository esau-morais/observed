## Build from source

You need [Bun](https://bun.sh) 1.4.2 or later.

```sh
git clone https://github.com/esau-morais/observed
cd observed
bun install
bun run check
```

`bun run check` runs the typecheck, lint, tests, build and skills check, the same as CI. If it passes, your checkout works.

## The previous version

The first version of Observed is on the [`legacy`](https://github.com/esau-morais/observed/tree/legacy) branch and on npm as `@observed-software/cli@0.2.0-alpha.10`. It still works, but the rebuild replaces it and these docs don't cover it.
