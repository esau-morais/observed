The plan is a single binary built with Bun. After each agent turn it prints the receipt in your terminal, the same text that goes into a PR comment.

## observed receipt

```sh
observed receipt [revision]
```

Prints the receipt for `revision` from the newest record in `refs/observed/evidence`. `revision` is any commit name git accepts and defaults to `HEAD`. Run it inside the repository.

If the ref is missing, the commit has no record or a record was altered, it prints the reason to stderr, prints nothing to stdout and exits with code 1. [Where evidence lives](/docs/concepts#where-evidence-lives) shows how to fetch the ref.
