Observed runs your coding agent and shows what each change did to your app. It runs the app on the revision before the change and the revision after it, records screenshots, requests and errors on both, and prints a receipt. Checks written before the change decide what holds. No model gets a vote.

<Callout title="Being rebuilt">
  Observed is being rebuilt from its first version. The judge and the agent adapters are in
  progress, so there is nothing to install yet. These pages say what works today and mark the rest
  as in progress.
</Callout>

## A receipt

Here is an example of the receipt Observed prints for a journey. It is plain text, so it fits a terminal, a PR comment or a phone notification.

```txt
Pay for the order
  changed  Screenshot · 1840 pixels in 1 region
  changed  Requests · 1 request fewer on the candidate
  checked  One POST /orders per click · base 2 · candidate 1 · exactly 1
  checked  Button reads Saving… while saving · Exactly one button element with text "Saving…".
No regression · 2 checked, 2 changed, 0 unknown, 0 failed
```

Each line starts with its state, then names what it is about and the evidence. `checked` means a check from before the change passes. `changed` means the screenshot or the request count differs, so you decide whether it was meant. The last line is the judge's conclusion and a count for each state. [Concepts](/docs/concepts) lists all four states.

## How it works

- Your agent (Claude Code, Codex, opencode or Muse) writes the change.
- Observed runs your app on both revisions and records what happened.
- Checks that existed before the change decide what holds. Missing evidence is unknown, never a pass.
